# Карта полей: УПД, титул покупателя (titleIndex=1, КНД 1115132)

Версия: `upd-title1-fieldmap-v1`. XSD: `ON_NSCHFDOPPOK_1_997_02_05_03_01`. Шаблон: `upd-title1-v1`.
Бизнес-правила: `upd-title1-business-v1`. Формат листа: A4 портрет.

Титул подтверждает принятие товаров (работ, услуг) по документу продавца. Он ссылается на файл продавца и
не воспроизводит его товарную таблицу, суммы и подписи.

Дисклеймер обязателен: статус завершения сделки нельзя вывести только из этого файла; наличие `ЭП` и
сведения о подписантах не доказывают действительность подписи; товарная таблица продавца не
воспроизводится.

Остальные содержательные значения — в приложении того же PDF; `unmapped` запрещён.
