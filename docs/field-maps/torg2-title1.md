# Карта полей: ТОРГ-2, титул продавца (titleIndex=1, КНД 1175015)

Версия: `torg2-title1-fieldmap-v1`. XSD: `DP_PRIRASXDOP_1_994_02_05_01_01`. Шаблон: `torg2-title1-v1`.
Бизнес-правила: `torg2-title1-business-v1`. Формат листа: A4 портрет.

Титул содержит только дополнительные сведения продавца к документу покупателя. Он не воспроизводит
товарные строки, суммы, расхождения и подписи первого титула.

не воспроизводится.

Остальные содержательные значения — в приложении того же PDF; `unmapped` запрещён.
