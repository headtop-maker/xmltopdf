# Карта полей: УПД 5.03, титул продавца (titleIndex=0, КНД 1115131)

Версия карты: `upd-title0-fieldmap-v1`. Ревизия XSD: `ON_NSCHFDOPPR_1_997_01_05_03_05`
(SHA-256 `f98a1ac91cb840ff341976f7636d8a98d51a43e9b1cbbf3e97386551aacdb49a`).
Шаблон: `upd-title0-v1`. Бизнес-правила: `upd-business-v1`.

Пути указаны относительно `/Файл/Документ`. Любое непустое значение, не перечисленное ниже, попадает в
приложение того же PDF с подписью из аннотаций XSD; `unmapped` запрещён.

## 0. Функция документа

Функция берётся из `@Функция` (обязательный атрибут) и определяет печатный смысл:

| Значение | Печать | Статус |
| --- | --- | --- |
| `СЧФ` | Счёт-фактура, без раздела отгрузки | реализовано |
| `ДОП` | Документ об отгрузке, без титула счёта-фактуры | реализовано |
| `СЧФДОП` | Универсальный передаточный документ: счёт-фактура + отгрузка | реализовано |
| `СвРК` | Сведения о реализации комиссионером (агентом) товаров комитента (принципала); не счёт-фактура | реализовано (структурная форма) |
| `СвЗК` | Сведения о закупке комиссионером (агентом) товаров для комитента (принципала); не счёт-фактура | реализовано (структурная форма) |

Если у функции `СЧФ` присутствует `СвПродПер`, данные отгрузки не печатаются в счёте-фактуре и уходят в
приложение; бизнес-правила дают предупреждение `TRANSFER_DATA_IN_INVOICE`.

## 7. Приложение и технические поля

- Остаток любых содержательных значений — в приложении с русской подписью, путём из имён элементов и
  значением; приложение является частью того же PDF.
- `technical` (allowlist): `ВерсПрог`, `КодРегион` при напечатанном `НаимРегион`, `КодСтр = 643`,
  `ИдФайлИнфПол`, `СоглСтрДопИнф`. Причина фиксируется в покрытии.
- Пустое значение — `—`, ноль — `0`; даты — `ДД.ММ.ГГГГ` без пересчёта часовых поясов; ставки НДС — как
  в XML, включая `22%` и `22/122`.
