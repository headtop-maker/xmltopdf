# Карта полей: ТОРГ-2, титул покупателя (titleIndex=0)

Версия карты: `torg2-title0-fieldmap-v1`. Ревизия XSD: `DP_PRIRASXPRIN_1_994_01_05_01_04`
(SHA-256 `6139596b95a3f4635ea0eab34fab33ce4e0f4fbebe4282fac043760884d36084`).
Шаблон: `torg2-title0-v1`. Бизнес-правила: `torg2-business-v1`.

Карта описывает основные поля. Механизм покрытия автоматически относит любое не перечисленное здесь
содержательное значение в приложение того же PDF; молчаливая потеря данных запрещена. Пути указаны
относительно `/Файл/Документ`, если не указано иное.

## 6. Приложение и технические поля

- Любое непустое значение, не потреблённое основной картой, попадает в приложение «Реквизиты исходного
  XML, не вошедшие в основной бланк» с русской подписью из аннотаций XSD, путём и значением.
- Статус `technical` (allowlist): `ВерсПрог`, `ИдОтпр`, `ИдПол`, `КодСтр = 643`, `ИдФайлИнфПол`,
  `КодГАР`. Каждое значение сохраняется в исходном XML и метаданных артефакта; причина указана в
  `note` покрытия.
- `unmapped` запрещён: при его появлении конвертация завершается `422 UNMAPPED_DATA`.

## 7. Правила форматирования

- Деньги: decimal-арифметика, 2 знака, разделитель разрядов — неразрывный пробел, десятичный — запятая.
  Исходное строковое значение хранится отдельно.
- Количества: до 3 знаков, без лишних нулей, разряды группируются.
- Даты: только `ДД.ММ.ГГГГ`; строки не переводятся через `Date`/UTC; даты разных блоков не объединяются.
- ИНН, КПП, ОКЕИ, артикулы, номера — строки, ведущие нули сохраняются.
- Пустое значение — `—`; явный ноль — `0`. Отсутствие, пустая строка и ноль различаются.
- Ставки НДС печатаются как в XML (`10%`, `22/122`), без пересчёта и без замены исторических ставок.
