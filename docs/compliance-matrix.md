## Сопутствующие статусы

| Область | Статус |
| --- | --- |
| Приём binary XML (octet-stream, application/xml, text/xml) | реализовано, проверено |
| Кодировки UTF-8 (BOM/без), windows-1251, UTF-16LE/BE | реализовано, unit-тесты |
| XXE/DTD/PI/XInclude | запрещено до XSD, тесты |
| XSD-валидация полного XML | реализовано (`xmllint --nonet`), 4 схемы закреплены и сверены по SHA-256 |
| Бизнес-правила | `torg2-business-v1` (ТОРГ-2 t0) и `upd-business-v1` (УПД t0): арифметика, НДС, функция/отгрузка; предупреждения не исправляют данные |
| Контроль покрытия полей | реализовано: `rendered` / `appendix` / `technical`, `unmapped` → 422 |
| УПД: функции СЧФ, ДОП, СЧФДОП | реализовано, синтетические обезличенные fixtures, 3 варианта печати |
| УПД: функции СвРК, СвЗК | распознаются, печать реализована структурно (функциональный заголовок + дисклеймер), нормативная форма не утверждена |
| PDF: A4 landscape, встроенные шрифты, текст извлекается | реализовано, проверено локально и в Docker |
| Docker: non-root, Chromium sandbox, read-only rootfs, tmpfs | собрано; в контейнере проверены все четыре титула (3/2/1/1 страниц), портретные вторые титулы и встроенные шрифты |
| Отсутствие шифрования/JS/вложений/AcroForm | проверяется после рендера |
| Хранение файлов | не выполняется: PDF существует в памяти, отдаётся по ссылке с TTL 15 минут |
| Рестарт и in-memory кэш | после рестарта ссылка даёт 404, кэш пуст, повторный рендер детерминирован; integration-тесты (`lifecycle.test.ts`) |
| Повторная отправка | дедупликация в памяти: те же байты и параметры печати → тот же PDF (`cached: true`); тесты |
| Внешняя подпись | контракт и технический round-trip; целевое средство не испытано |
| PDF/A | не поддерживается |
| Несколько реплик / внешнее хранилище | не поддерживается: кэш локален для процесса, БД и S3 отсутствуют |
| Сверка вёрстки ТОРГ-2 с эталоном заказчика | выполнена на четырёх образцах; совпадают шрифты, сетки, числа и пагинация 4/4/5/4 |
| Сверка вёрстки УПД (бланк Saby) | частично: одна страница, сетка 16 граф и линии подписей совпадают с эталоном №262 в пределах ~1 pt; отличия — Liberation Sans вместо Tahoma, X-сдвиги заголовков граф, нет пагинации при 4+ строках; см. `docs/reports/upd-saby-layout-draft.md` |
| Нормативная приёмка печатных форм (ТОРГ-2 и УПД) | не выполнялась, профили не утверждены |
| Автотесты | 72 теста: unit, XSD-матрица по 4 схемам, HTTP → PDF, безопасность, дедупликация по содержимому, функции УПД, вторые титулы, шаблон Saby |
| Визуальная регрессия | 15 эталонов; на linux-образе прогон 11 страниц дал 0 расхождений, набор из 15 страниц после добавления `СвРК`/`СвЗК` требует перегенерации на Linux (Docker Desktop исчерпал диск) |
| Нагрузка | p95 1,76 с (УПД, c=2), 3,61 с (1 000 строк, 55 страниц), очередь 2+10 → 503; см. `docs/reports/load-test.md` |
| Квоты владельца | фиксированное окно 60 с, `RATE_LIMIT_PER_MINUTE` (по умолчанию 300, 0 — off), 429 + Retry-After; тесты |
