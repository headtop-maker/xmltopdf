# Ручной тест-кейс: УПД (СЧФДОП) из XML в PDF

Проверка печатной формы УПД 5.03, КНД 1115131, функция СЧФДОП. Эталон оформления —
PDF Saby «Счет-фактура и УПД 31.10.26 № 262 = 84 000.00 в т.ч. НДС 4 000.00».

Обозначения: `BASE=http://localhost:3000`, `KEY=local-test-key`.

## 1. Предусловия

```bash
npm run build && npm start          # обычный режим
# или черновик бланка Saby:
UPD_SABY_LAYOUT=true npm start
```

Файлы:

| Документ | XML | Эталон |
|---|---|---|
| №262, 31.10.2026 | `ON_NSCHFDOPPR_2BM-…_20261102_….xml` | PDF №262, XLSX №262 |
| №185, 31.07.2026 | `ON_NSCHFDOPPR_2BEf…_20260804_….xml` | XLSX №185 |

Инструменты: `curl`, `pdftotext`, `pdftoppm`, просмотрщик PDF.

## 2. TC-UPD-01. Конвертация и метаданные

```bash
curl --fail-with-body -D upd.headers \
  -H "X-API-Key: $KEY" \
  -H 'Content-Type: application/octet-stream' \
  --data-binary @<путь к XML> \
  "$BASE/api/v1/conversions" -o upd.pdf

grep -iE 'x-page-count|x-document-family|x-document-function|x-schema-revision|x-business-status|x-unmapped-count' upd.headers
pdfinfo upd.pdf | grep Pages
```

Ожидается для №185:

- `201`, `document.family = UniversalTransferDocument`;
- `document.titleIndex = 0`, `document.function = СЧФДОП`;
- `validation.business = passed`, `unmappedCount = 0`;
- в черновике `pageCount = 1` (обычный режим — 3).

## 5. TC-UPD-04. Итоги и арифметика

- 222 600.00 × 5 / 100 = 11 130.00;
- 222 600.00 + 11 130.00 = 233 730.00;
- суммы в PDF совпадают с XML и XLSX;
- формат — пробел в тысячах, точка в дробной части.

## 7. TC-UPD-06. Запрещённые элементы

В PDF не должно быть:

- печатей, факсимиле, QR-кодов;
- синих штампов «ДОКУМЕНТ ПОДПИСАН ЭЛЕКТРОННОЙ ПОДПИСЬЮ»;
- слова «электронно» вместо подписи;
- данных приёмки покупателя (дата, ФИО, должность принявшего), если их нет в XML;
- подписных утверждений «подписано», сертификатов, кодов оператора ЭДО.

Проверка:

```bash
pdftotext -layout upd.pdf - | grep -iE "электронно|подписан|сертификат" || echo "OK"
```

## 8. TC-UPD-07. Несколько строк

3. Сконвертировать.

Ожидается: строки идут с шагом 18 pt, итоги и нижний блок сдвигаются вниз;
до 3 строк — одна страница; 4+ строк требуют пагинации (пока не реализована).

## 11. Известные ограничения

1. Tahoma в окружении нет, используется Liberation Sans — часть строк переносится иначе.
2. Заголовки отдельных граф смещены по X на 5–14 pt.
3. Более 3 строк — нужна пагинация.
4. Банковские реквизиты собираются эвристикой «первая запятая → в».
5. Черновик включается `UPD_SABY_LAYOUT=true`; по умолчанию работает старый шаблон.
