# УПД: проверка вариантов (после фиксации образца УП-13093)

Дата: 2026-11-10. Образец УП-13093 зафиксирован: его PDF после всех изменений
побайтово совпадает с контрольным (`cmp` — идентичны).

## Что проверено

| Вариант | Документ | Результат |
|---|---|---|
| ООО-продавец, 12 строк, ставки 10 % / 22 % / без НДС | `test/fixtures/stress/upd-filled.xml` | 2 страницы, таблица продолжается с шапкой, блок подписей на последней странице |
| 40 строк, ставки 22/10/20/5/0/без НДС, имя 750 символов | `test/fixtures/stress/upd-long-many.xml` | 3 страницы, строки не разрываются, итог 1 390 250,00 / 148 412,60 / 1 538 662,60 |
| Имя 1999 символов (предел XSD) | `test/fixtures/stress/upd-overlong-name.xml` | 3 страницы, весь текст 20/20 фрагментов, без обрезки |

Для ООО строка «Ответственный за правильность…» печатает должность подписанта
(`ГЕНЕРАЛЬНЫЙ ДИРЕКТОР`), а не «Индивидуальный предприниматель»; строки руководителя и
главного бухгалтера заполняются из `Подписант`, строка ИП остаётся пустой.

## Найденный дефект и исправление

Строка с именем 1999 символов выше страницы. При `break-inside: avoid` Chromium не мог
разместить её и **обрезал хвост текста** (в PDF оставалось 18 из 20 фрагментов, остальное
терялось молча).

Исправление: шаблон оценивает высоту строки (число строк наименования × 8,05 pt) и для строк
выше 400 pt добавляет класс `split` с `break-inside: auto`. Такая строка переносится на
следующую страницу по строкам текста, шапка повторяется; обычные строки по-прежнему не
разрываются. Проверка: 20/20 фрагментов, 3 страницы.

## Многостраничность

- Шапка таблицы повторяется на каждой странице (служебная строка 12 pt сверху).
- Строки обычной высоты не разрываются между страницами.
- Блок подписей всегда идёт после итоговой строки на последней странице таблицы.
- «Документ составлен на N листах» (демо-режим) считает реальное число страниц.

## Разбиение строки выше страницы и колонтитулы

- Строка, которая не помещается на странице, делится шаблоном на части по ≈37 строк текста
  (300 pt). Первая часть несёт все числа позиции, продолжения — только наименование
  с пометкой «Продолжение позиции N»; количество, стоимость и НДС печатаются один раз.
  Количество частей считается по ширине колонки наименования, шрифт не уменьшается.
- Строки, которые помещаются на следующей странице, по-прежнему переносятся целиком.
- Итоговая строка привязана к предыдущей (`break-before: avoid`), поэтому страница
  с повторённой шапкой и одним итогом больше не появляется.
- «Документ составлен на N листах» заполняется реальным числом страниц: рендер выполняется
  дважды (первый проход — подсчёт, второй — подстановка). Для одностраничного документа
  второго прохода нет.
- На многостраничных УПД появился колонтитул: слева «УПД № … от …», справа
  «Страница N из M». Для одностраничных колонтитул не печатается, контрольный образец
  УП-13093 не меняется, кроме поля «на N листах» (теперь «1»).
- «Иные сведения» больше не обрезаются: текст переносится (3 строки в поле), многоточие
  и фиксированная высота убраны; правое поле начинается с X=560, чтобы не прилипать
  к заголовку.

## Ограничения

- Слишком длинное наименование делает строку выше страницы — печатается с переносом,
  но выглядит не как в СБИС (там такие данные не встречались).
- Для ООО роль ответственного берётся из `Должн` подписанта; если в XML её нет —
  «Руководитель организации».
