## Вертикальное смещение

Причина — две независимые разницы:

1. **Лишняя строка 5б.** Она печаталась всегда. В формате `ДОП` (документ об отгрузке без
   счёт-фактурной части) эта строка отсутствует — теперь выводится только для `СЧФДОП`.
   Это снимает 17,9 pt и не является отрицательным margin.
2. **Высоты строк таблицы.** У нас все строки были `height: 18pt`; в эталоне высота по
   содержимому: 9,7 pt для однострочной и 18 pt для двухстрочной. Снято ещё 8,3 pt.

Дополнительно шапка таблицы была 6 pt — в эталоне 7 pt при `line-height: 7,4pt`, иначе шапка
разъезжается. Ширина таблицы в эталоне — 813,2 pt (не 805), колонки пересчитаны по границам
эталона: 65,2 / 16,5 / 135,0 / 47,2 / 17,3 / 44,2 / 42,9 / 40,6 / 56,9 / 40,7 / 32,0 / 55,5 /
57,2 / 40,3 / 40,7 / 81,0.
