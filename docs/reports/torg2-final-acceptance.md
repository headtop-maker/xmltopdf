# TORG-2: финальная приёмка

## Что считается выполнением

TORG-2 имеет два режима:

1. **Встроенный HTML-рендер** — по умолчанию; 4 страницы, ближе к Saby,
   без внешних зависимостей.
2. **Внешний шаблонный рендер** (`VISLIB_ENABLED=true`) — официальный
   `.sved`-шаблон TORG-2 через библиотеку визуализации; все поля шаблона,
   точная геометрия шаблона, включается оператором.

Оба режима используют один API и один feature flag; по умолчанию внешний
рендер выключен.

## Доказательства

### Встроенный режим

- XML: `test-output/current/source.xml`;
- PDF: `torg2-current.pdf`;
- 4 страницы, A4 landscape, SHA-256 `f79dfa0e…`;
- контрольные значения: 2/89,10/16,07 и 2/96,46/8,77;
- 60+ тестов, сборка чистая.

### Внешний шаблонный режим

- тот же XML через `POST /api/v1/conversions`;
- HTTP 201, 7 страниц, 494 683 байта;
- SHA-256 `f8e91bd2…`;
- PDF: `test-output/vislib/torg2-vislib-service.pdf`;
- первая страница содержит версию библиотеки `prod-2.1.2.329`, редакция
  шаблона 17.

### Feature flag

```bash
VISLIB_ENABLED=false                 # default
VISLIB_JAR=/path/templater-extend-lib.jar
VISLIB_TEMPLATES_DIR=/path/Templates
```

- если JAR или каталог шаблонов не заданы — режим выключен;
- при выключенном флаге сервис отдаёт прежние 4 страницы;
- JAR и `.sved` не входят в репозиторий и Docker; это operator-supplied
  зависимость, требуется проверка лицензии Aspose/ГНИВЦ.

## Сравнение с Saby

Отчёт: `torg2-v2-vs-reference.md`, `torg2-vislib-sidecar.md`.

Ключевые различия внешнего шаблонного вывода с Saby:

- 7 страниц вместо 4;
- служебная страница с версией библиотеки;
- нет повтора шапки на продолжении таблицы;
- дубли номеров строк;
- подпись «цена» над суммой в шапке расхождений;
- пустое «Заключение комиссии» печатается как заголовок.

Это поведение самого официального шаблона/библиотеки, а не нашего
HTML-рендера. Встроенный режим эти дефекты не воспроизводит.

## Ограничения

- Попытка полностью воспроизвести Excel-геометрию в HTML (компилятор
  `scripts/compile-sved-layout.py` + preview) показала наложения в узких
  колонках и merge-границах; preview оставлен экспериментальным и в сервис
  не включён.
- Для «пиксель в пиксель» с Saby нужен отдельный эталонный набор и допуски;
  официальный шаблон и Saby — разные вёрстки.

## Итог

Цель в части «все поля утверждённой формы + шаблонный рендер + feature flag +
сравнение + отчёт» закрыта через опциональный внешний шаблонный рендер.
Встроенный рендер остаётся безопасным дефолтом и не ломает сервис.
